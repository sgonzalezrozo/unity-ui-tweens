## Status

Pre-release (`0.4.6`), by a single author, not yet used in a shipped game. Its API and behavior may change before `1.0.0`. Known gaps are listed under [Limitations](troubleshooting.md#limitations).

## Versioning

Until `1.0.0`, minor versions (`0.x.0`) can include breaking changes, and patch versions (`0.x.y`) don't. Breaking changes are marked **Breaking** in the [changelog](../CHANGELOG.md).

## Contributing

Bug reports and pull requests are welcome; please open an issue before a large change. See the [contributing guide](../.github/CONTRIBUTING.md) and [security policy](../.github/SECURITY.md). Planned work is tracked in [issues](https://github.com/sgonzalezrozo/unity-ui-tweens/issues).
