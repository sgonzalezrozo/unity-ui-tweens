# AI Coding Agents

[← Back to README](../README.md)

Coding agents write C# files, and this package is newer than their training data. Give them its rules so they use the real API:

1. Copy [`agent-rules.md`](agent-rules.md) into your project's agent rules, for example `AGENTS.md`, `CLAUDE.md` or `.cursor/rules/ui-tweens.md`.
2. For a whole Unity architecture with a verify loop, add [Unity Architecture Agents](https://github.com/sgonzalezrozo/unity-architecture-agents). It detects this package and adapts its code.

There are no MCP tools for UI Tweens yet. The rules file works with any agent that reads project files. It hasn't been tested with agents beyond the author's own projects.
